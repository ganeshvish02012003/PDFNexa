## ✨ Why PDFNexa?

PDFNexa brings essential PDF utilities together in one application, with a focus on usability, practical document workflows, and self-managed PDF processing.

* 📑 Merge and split PDF documents
* 🔄 Convert PDFs to images and images to PDFs
* 🗜️ Compress PDFs using supported compression modes
* 🔐 Protect PDFs with password security
* 🖊️ Add annotations, watermarks, and page numbers
* 🔃 Rotate and organize PDF pages
* ⚙️ Built with modern JavaScript technologies

## ✨ Features

### 📑 PDF Management

* **Merge PDF** — Combine multiple PDF files into one document.
* **Split PDF** — Extract or separate PDF pages.
* **Organize PDF** — Rearrange and manage PDF pages.
* **Rotate PDF** — Rotate PDF pages to the desired orientation.

### 🔄 PDF Conversion

* **PDF to Images** — Convert PDF pages into images.
* **Images to PDF** — Create PDF documents from image files.

### 🗜️ PDF Optimization

* **Compress PDF** — Reduce PDF file size using different compression modes.
* **Add Page Numbers** — Insert page numbers into PDF documents.

### 🔐 PDF Security

* **Protect PDF** — Add password protection to PDF documents.
* **Unlock PDF** — Remove supported PDF restrictions when authorized.

### 🖊️ PDF Editing & Information

* **Watermark PDF** — Add watermarks to PDF documents.
* **Annotate PDF** — Add supported annotations to PDF files.
* **PDF Metadata** — View or manage document metadata.

> Feature availability and behavior may depend on the current implementation and the PDF file being processed.

## 🧩 How It Works

1. Select a PDF utility.
2. Upload the required PDF or image files.
3. Choose the available processing options.
4. Let the backend process the document.
5. Download the resulting file.

## 🔒 Privacy & Security

PDFNexa is designed around a self-managed PDF processing backend. Before uploading sensitive documents, review the deployment's file-storage, temporary-file cleanup, and security configuration.

Do not upload confidential documents to a public or untrusted deployment.
